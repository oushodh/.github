# Oushodh

Medicine data for Bangladesh, through one API.

Oushodh gives brands, generics, strengths, manufacturers and MRP for the medicines sold in Bangladesh, checked against the DGDA register. Agencies and developers use it to build pharmacy, hospital and health apps.

- Website: [oushodh.dev](https://oushodh.dev)
- Docs: [oushodh.dev/docs](https://oushodh.dev/docs)
- Get an API key: [app.oushodh.dev](https://app.oushodh.dev)
